# Social Media Engagement Analysis with Python

## Project Overview

This project analyzes social media data using Python and pandas to understand how different content categories and post types perform. The analysis examines likes, comments, shares, views, and followers to identify patterns in engagement and reach.

## Objective

The goal of this project is to explore social media performance and identify which content categories and post types perform better across different engagement metrics. The project also examines relationships between audience size, reach, and engagement.

## Dataset

The dataset contains social media post information, including:

- Date
- Category
- Post Type
- Likes
- Comments
- Shares
- Views
- Followers

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis

The project analyzes:

- Average likes, comments, shares, and views by category
- Post type performance
- Views vs. likes
- Followers vs. views
- Performance over time
- Correlations between engagement and reach metrics

## Key Findings

- Health had the highest average likes and comments.
- Family had the highest average shares.
- Music had the highest average views.
- Text posts had the highest average likes.
- Link posts had the highest average comments and views.
- Image posts had the highest average shares.
- The major performance metrics showed very weak correlations with one another.

## Recommendations

Different content strategies may be useful depending on the desired engagement goal. Health content may be useful for increasing likes and comments, while Family content may encourage more shares. Link, Text, and Image posts each performed better for different engagement metrics.

## Limitations

The analysis is based on the available dataset and does not include factors such as content quality, posting time, audience demographics, or platform algorithms. The correlations identify linear relationships but do not establish causation.

## Conclusion

This project demonstrates how Python and data visualization can be used to analyze social media performance, identify patterns, and develop data-driven recommendations.
